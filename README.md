# PRouter

Automatische Rundrouten auf OpenStreetMap – zum Laufen, für Trail Runs und mit dem Rennrad.
Läuft komplett im Browser; Favoriten werden nur auf dem jeweiligen Gerät gespeichert.

## Daten und Dienste

- Kartendaten © [OpenStreetMap](https://www.openstreetmap.org/copyright)-Mitwirkende (ODbL)
- Routenberechnung: [BRouter](https://brouter.de) (öffentlicher Server)
- Ortssuche: [Photon](https://photon.komoot.io) von komoot
- Adressindex (`adressen.json`): Gebäudedaten LoD2 der Bayerischen Vermessungsverwaltung, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.de)
- Bibliotheken: [Leaflet](https://leafletjs.com), [Motion](https://motion.dev)
